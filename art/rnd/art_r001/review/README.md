# Review evidence

`asset-contract-report.json` is generated by the Godot validator. It records per-cell geometry and alpha when real sheets exist, otherwise missing outputs and BLOCKED status. It never edits source pixels. Visual continuity scores require actual generated art; synthetic validator fixtures are not art-quality evidence. Native comparison captures are under `docs/screenshots/`.

`direction-master-geometry.json` measures four real master canvases. `source-contract-report.json` measures the ten actual down frames, checks source hashes/rig structure and lists30missing frames; structural checks do not override native mechanics rejection. `native-direction-preflights.json` preserves all six actual failing native checks. `export-assembly.json` refuses incomplete atlases. `display-evidence.json` records actual1280×720/exact2× comparison captures and preview mode. Idle/Walk four-direction review screenshots are explicitly INCOMPLETE; blank/missing directions are never accepted art.
